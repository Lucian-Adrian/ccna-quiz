# QuizOS CCNA Practice

Mobile-first CCNA quiz trainer built from the `quizos-v1` question data.

## Study structure

- Modules 1-3
- Modules 4-7
- Modules 8-10
- Modules 11-13
- Modules 14-15
- Modules 16-17
- Midterm 1: Modules 1-7
- Midterm 2: Modules 8-17
- All modules: Modules 1-17

## Modes

- Practice: immediate answer checking and explanations.
- Exam: randomized 24-question exam from answerable multiple-choice questions.
- Stats: local device progress by module and midterm.

## Development

```bash
npm install
npm run dev
npm test
npm run build
```

The GitHub Pages workflow deploys the `quizos-v2` branch with pnpm.
