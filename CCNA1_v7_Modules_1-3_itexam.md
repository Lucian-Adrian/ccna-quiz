## Question 1

During a routine inspection, a technician discovered that software that was installed on a computer was secretly collecting data about websites that were visited by users of the computer. Which type of threat is affecting this computer?

- [ ] DoS attack​
- [ ] identity theft
- [x] **spyware**
- [ ] zero-day attack

> [!NOTE]
> **Explanation:** **Correct Answer:** spyware

**Concept & Details:**
* **Spyware** is malware (malicious software) designed to infect a computer, run secretly in the background, and gather information about user behavior (such as websites visited, passwords, or personal data) without their consent. The gathered information is then transmitted to the attacker.
* **Why other options are incorrect:**
  * **DoS (Denial of Service) attack:** An attack that aims to shut down or overload a machine or network, making it inaccessible to its intended users, rather than stealing data.
  * **Identity theft:** This is the *outcome* or crime of using someone else's personal information for fraudulent purposes, rather than the specific type of software threat itself.
  * **Zero-day attack:** A security vulnerability or threat that is exploited before a software patch or defense is available from the vendor.

## Question 10

What two criteria are used to help select a network medium from various network media? (Choose two.)

- [ ] the types of data that need to be prioritized
- [ ] the cost of the end devices utilized in the network
- [x] **the distance the selected medium can successfully carry a signal**
- [ ] the number of intermediate devices installed in the network
- [x] **the environment where the selected medium is to be installed**

> [!NOTE]
> **Explanation:** **Correct Answer:** the distance the selected medium can successfully carry a signal, the environment where the selected medium is to be installed

**Concept & Details:**
* Network media refers to the physical path (copper, fiber-optic, or wireless) that carries signals. When choosing a medium, key engineering considerations include:
  1. **Distance:** Different media have different signal degradation rates. For example, UTP copper is limited to 100 meters, while single-mode fiber-optic can run for kilometers.
  2. **Environment:** Factors like electromagnetic interference (EMI) from heavy machinery or outdoor weather dictate whether you should use shielded copper, fiber-optic (which is immune to EMI), or wireless.
* **Why other options are incorrect:**
  * Data prioritization is managed by Software/QoS protocols, not by the physical media.
  * The cost of end devices (PCs, servers) and the number of intermediate devices (switches, routers) do not directly dictate the type of cable or medium chosen.

## Question 13

Passwords can be used to restrict access to all or parts of the Cisco IOS. Select the modes and interfaces that can be protected with passwords. (Choose three.)

- [x] **VTY interface**
- [x] **console interface**
- [ ] Ethernet interface
- [ ] boot IOS mode
- [x] **privileged EXEC mode**
- [ ] router configuration mode

> [!NOTE]
> **Explanation:** **Correct Answer:** VTY interface, console interface, privileged EXEC mode

**Concept & Details:**
* Cisco IOS (Internetwork Operating System) provides security at different access points:
  1. **Console interface:** The physical port used for direct local command-line access. Protected using the `line console 0` configuration.
  2. **VTY (Virtual Teletype) interface:** Virtual ports used for remote access over the network (via SSH or Telnet). Protected using the `line vty` configuration.
  3. **Privileged EXEC mode:** The mode that allows administrative commands and access to global configuration. Protected using the `enable secret` or `enable password` command.
* **Why other options are incorrect:**
  * Individual physical Ethernet interfaces or configuration modes (like router configuration mode) cannot have passwords applied directly to block command entry; access is controlled via the console/VTY interfaces or EXEC modes.

## Question 14

Which interface allows remote management of a Layer 2 switch?

- [ ] the AUX interface
- [ ] the console port interface
- [x] **the switch virtual interface**
- [ ] the first Ethernet port interface

> [!NOTE]
> **Explanation:** **Correct Answer:** the switch virtual interface

**Concept & Details:**
* A Layer 2 switch switches traffic based on physical MAC addresses and does not natively need an IP address to function. However, to manage the switch remotely (using SSH, Telnet, or HTTP), it must be assigned an IP address. Since physical ports on a Layer 2 switch cannot have IP addresses assigned directly, this IP address is configured on a software-based **Switch Virtual Interface (SVI)**, typically VLAN 1 by default.
* **Why other options are incorrect:**
  * **Console port:** Used for local, physical configuration, not remote management over a network.
  * **AUX interface:** Used for out-of-band management via a modem connection, typically on routers, not remote LAN management.
  * **First Ethernet port:** Physical ports on a Layer 2 switch operate at Layer 2 and cannot be assigned an IP address directly for remote IP-based management.

## Question 16

While trying to solve a network issue, a technician made multiple changes to the current router configuration file. The changes did not solve the problem and were not saved. What action can the technician take to discard the changes and work with the file in NVRAM?

- [x] **Issue the reload command without saving the running configuration.**
- [ ] Delete the vlan.dat file and reboot the device.
- [ ] Close and reopen the terminal emulation software.
- [ ] Issue the copy startup-config running-config command.

> [!NOTE]
> **Explanation:** **Correct Answer:** Issue the reload command without saving the running configuration.

**Concept & Details:**
* Cisco devices use two main configuration files:
  1. **Running Configuration (stored in RAM):** The active file that updates immediately with every command entered. It is volatile, meaning it is lost when power is cut or the device reboots.
  2. **Startup Configuration (stored in NVRAM):** The saved file that is loaded when the device boots up. It is nonvolatile.
* If a technician makes mistakes in the running configuration and has *not* saved them, issuing the `reload` command will reboot the device, clearing RAM and loading the clean configuration from NVRAM (Non-Volatile Random Access Memory).
* **Why other options are incorrect:**
  * **copy startup-config running-config:** This is additive. It merges NVRAM settings into RAM rather than overwriting RAM completely, so the unwanted changes may persist.
  * **vlan.dat:** Contains VLAN settings on switches, deleting it will erase VLAN configurations, not discard unsaved router configuration changes.
  * **Reopening terminal software:** Simply closes the console view; the router is still running the modified configuration in its RAM.

## Question 21

What are two characteristics of RAM on a Cisco device? (Choose two.)

- [ ] RAM provides nonvolatile storage.
- [x] **The configuration that is actively running on the device is stored in RAM.**
- [x] **The contents of RAM are lost during a power cycle.**
- [ ] RAM is a component in Cisco switches but not in Cisco routers.

> [!NOTE]

* **RAM (Random Access Memory)** is volatile memory on Cisco devices. It has the following key attributes:
  1. It stores the active **running configuration** (`running-config`), routing tables, ARP cache, and packet buffers.

  * Both routers and switches utilize RAM.
  * Multiple versions of the IOS image files and system configuration files are stored in **Flash memory** or **NVRAM**, which are nonvolatile.

## Question 23

How is SSH different from Telnet?

- [ ] SSH makes connections over the network, whereas Telnet is for out-of-band access.
- [x] **SSH provides security to remote sessions by encrypting messages and using user authentication. Telnet is considered insecure and sends messages in plaintext.**
- [ ] SSH requires the use of the PuTTY terminal emulation program. Tera Term must be used to connect to devices through the use of Telnet.
- [ ] SSH must be configured over an active network connection, whereas Telnet is used to connect to a device from a console connection.

> [!NOTE]
> **Explanation:** **Correct Answer:** SSH provides security to remote sessions by encrypting messages and using user authentication. Telnet is considered insecure and sends messages in plaintext.

**Concept & Details:**
* **SSH (Secure Shell)** and **Telnet** are both network protocols used to connect to devices remotely. The primary difference is security: SSH encrypts all communications (including usernames and passwords) to prevent eavesdropping, while Telnet transmits everything in clear, unencrypted plaintext, which can be easily captured by attackers.
* **Why other options are incorrect:**
  * Both protocols run over the network (in-band). Neither is for out-of-band console access.
  * Emulation software like PuTTY and Tera Term can handle both SSH and Telnet connections.
  * Neither protocol is used over a physical console cable connection; console configuration uses serial protocols.

## Question 27

Match the description with the associated IOS mode. (Not all options are used.)

> [!NOTE]
> **Explanation:** **Correct Answer:** Match the descriptions to their respective modes.

**Concept & Details:**
* **User EXEC Mode:**
  * **Description:** First entry mode upon connecting. It has a limited number of basic monitoring commands and does not allow configuration changes.
  * **Prompt:** `Switch>` or `Router>`
* **Privileged EXEC Mode:**
  * **Description:** Allows access to all device commands, detailed troubleshooting tools, and configuration management commands. It is entered from User EXEC mode using the `enable` command.
  * **Prompt:** `Switch#` or `Router#`
* **Global Configuration Mode:**
  * **Description:** Used to modify settings that affect the device as a whole (such as hostname or routing settings). It is entered from Privileged EXEC mode using the `configure terminal` command.
  * **Prompt:** `Switch(config)#` or `Router(config)#`
* **Subconfiguration Modes (e.g., Interface / Line Configuration):**
  * **Description:** Used to configure specific parts of the device, like an interface or a physical line/port.
  * **Prompts:** `Switch(config-if)#` (Interface mode) or `Switch(config-line)#` (Line mode)

- [ ] network layer

- [ ] network layer
- [ ] transport layer

## Question 76

A college is building a new dormitory on its campus. Workers are digging in the ground to install a new water pipe for the dormitory. A worker accidentally damages a fiber optic cable that connects two of the existing dormitories to the campus data center. Although the cable has been cut, students in the dormitories only experience a very short interruption of network services. What characteristic of the network is shown here?

- [ ] quality of service (QoS)
- [ ] scalability
- [ ] security
- [x] **fault tolerance**
- [ ] integrity

> [!NOTE]
> **Explanation:** **Correct Answer:** fault tolerance

**Concept & Details:**
* **Fault tolerance** is the design characteristic of a network that allows it to recover quickly from failures of devices, lines, or media without losing connectivity. A fault-tolerant network achieves this by having redundant (duplicate) paths. When one cable is cut, routing protocols immediately reroute traffic through an alternative path, minimizing disruption to users.
* **Why other options are incorrect:**
  * **quality of service (QoS):** Prioritizes specific types of traffic (like voice or video) over others during congestion.
  * **scalability:** The ability to grow and add new devices without degrading existing performance.
  * **security:** Protecting the network and its data from unauthorized access or damage.
